# GitHub Pages deployment

This branch publishes the static contents of `public/` from development branch `claude/pdf-learning-app-1i626u`, source commit `d1c79f23cda2fabda7cd0d2a98b978ee078d1bcd`.

Site: https://trainertechpro.github.io/Athlete-Creator-Blueprint/

GitHub Pages uses main at the repository root. To publish a future version, refresh these static files from the development branch's public directory. No build is required. Do not copy server files, environment files, credentials, or source PDFs. The optional server-backed AI coach is unavailable on Pages; the built-in coach works locally.
